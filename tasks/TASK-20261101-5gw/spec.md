## Feature Summary
This feature establishes full operational parity between the standard scroll view and the paginated Page View (`isPageMode`) in the Saliw Setlist Viewer (`SetlistViewerClient.tsx`). Specifically, it renders the floating "Edit Songs" FAB (`<AppendSongsButton />`) across all view modes and empty setlist states, wires incoming follower realtime stage sync events (`SONG_CHANGE` and `SECTION_CHANGE`) to navigate songs and reset sub-pages, enriches the Page View controls popover with CAGED shape selection, original key display, key reset, and follower leader-override controls, hoists compact song headers and YouTube video embeds outside the multi-column layout container to prevent pagination breakage, scopes chord drawer diagrams to the active song with capo offsets, suppresses keyboard navigation shortcuts during open modals, and ensures active song indexing resiliently reconciles when songs are added, deleted, or reordered.

## Acceptance Criteria
1. **"Edit Songs" FAB Visibility Across All Modes:** In `src/app/setlists/[id]/SetlistViewerClient.tsx`, `<AppendSongsButton />` is rendered whenever `isLeader` is `true` regardless of whether `isPageMode` is active (removing the `!isPageMode` guard).
2. **Empty Setlist State FAB Parity:** When a setlist contains zero songs (`songs.length === 0`) in Page View mode, the empty state displays the setlist empty notice and renders `<AppendSongsButton />` for leaders so that songs can be added directly without switching views.
3. **Modal & Drawer Keyboard Shortcut Guard:** When any modal dialog or drawer is open in Page View mode (`AppendSongsModal`, `YouTubeLinkModal`, `SetlistSettingsModal`, or `ChordDrawer`), pressing `Space`, `ArrowRight`, or `ArrowLeft` does not trigger song or sub-page navigation and does not call `e.preventDefault()` on non-navigation inputs.
4. **Active Song Index Reconciliation on Song Mutation:** When songs are added, removed, or reordered via `AppendSongsModal` or external sync while in Page View:
   - If the active song is still present (matched by `junctionId`), `activeSongIndex` automatically updates to match the song's new index in `songs`.
   - If the active song was deleted, `activeSongIndex` is clamped cleanly to `[0, Math.max(0, songs.length - 1)]` and `subPageIndex` resets to `0`.
5. **Follower Realtime Sync Callback Hook:** `useSetlistSync` (`src/hooks/useSetlistSync.ts`) accepts an optional `onRemoteSongChange?: (junctionId: string) => void` callback held in a stable `useRef`.
6. **Follower Realtime Song Navigation in Page View:** When a follower receives a valid `SONG_CHANGE` or `SECTION_CHANGE` broadcast on channel `setlist_sync:${setlistId}`, `onRemoteSongChange(junctionId)` is executed. In Page View mode, this callback switches `activeSongIndex` to the matching song, resets `subPageIndex` to `0`, and clears any local key override for that song so the follower stays locked to the leader.
7. **Page View Transpose Popover Original Key & Reset Button:** The Page View controls popover in `SetlistViewerClient.tsx` displays the song's original key indicator `(Orig: <originalKey>)` and renders a `"Reset"` button whenever `currentSongActiveKey !== currentSong.originalKey` that resets the song key back to `originalKey` (and broadcasts `KEY_CHANGE` if `isLeader && isLive`).
8. **CAGED Shape Picker in Page View Popover:** The Page View controls popover renders five CAGED shape buttons (`C`, `A`, `G`, `E`, `D`). Clicking an available shape sets `capo` to `getSemitoneOffset(shapeRoot, currentSongActiveKey)`, clicking the currently active shape resets `capo` to `0`, and shapes requiring capo fret `> 7` are disabled (`disabled` attribute and `aria-disabled="true"`).
9. **Follower Key Override Control in Page View:** When a follower (`isFollowing === true`) in Page View manually adjusts a song's key via the popover controls (`-1`, `+1`, key dropdown, or Reset), local override mode is activated for that song (ignoring leader `KEY_CHANGE` broadcasts for that song) and the popover renders `"Overriding leader • [Reset to Leader]"` which, when clicked, restores the leader's active key.
10. **Compact Song Header Live Sync Status Feedback:** In `src/components/client/SetlistSongSection.tsx`, when `isCompactHeader={true}` is active, the header renders `liveSyncState` indicators (`"Saving…"`, `"Synced"`, or error message) and `syncError` alerts alongside the Sync button for leaders (`isLeader === true`).
11. **Worship Leader & Lineup Summary in Page View:** In `SetlistViewerClient.tsx`, when `isPageMode` is active and either `worshipLeaderName` or `lineup.length > 0` is present, a compact single-line summary of the Worship Leader and Lineup is rendered in the header region instead of being omitted.
12. **YouTube Embed Container Hoisting & Viewport Parity:** In Page View mode, the compact song header and the YouTube video section (`SetlistSongSection.tsx` / `SetlistViewerClient.tsx`) are rendered outside (or span across) the CSS multi-column flow (`columns-1 lg:columns-2 xl:columns-3` with `translateX` sub-page transform) so that opening a 16:9 YouTube video embed does not squash into a single narrow column or translate off-screen when advancing sub-pages (`subPageIndex > 0`).
13. **Chord Drawer Scoping & Capo Offset in Page View:** In `SetlistViewerClient.tsx`, when `isPageMode` is active, `uniqueChords` passed to `<ChordDrawer />` is derived strictly from the currently active song (`currentSong`), and `<ChordDrawer />` receives `capoOffset={isPageMode ? currentSongCapo : 0}`.
14. **Artisan Design System & Styling Discipline:** All added or modified UI components strictly adhere to Saliw's Artisan palette (`brand-cream`, `brand-tan`, `brand-brown`, `brand-espresso`, `brand-darker`) with explicit `dark:` variant classes on all color utilities, without introducing generic Tailwind color utilities.
15. **Type Safety & Build Integrity:** All modifications pass `tsc --noEmit`, `eslint`, and existing unit tests (`vitest run`) without regressions.

## Out of Scope
- Displaying `SectionNavDeck` floating badge column in Page View mode (explicitly kept hidden in Page View per Q1.5).
- Enabling `AutoScrollToolbar` in Page View mode (remains disabled in Page View per TASK-20261020-347 AC-9).
- Modifying Supabase database schema, tables, migrations, RLS policies, or Server Action signatures in `src/app/actions/setlistActions.ts`.
- Modifying the standalone Song Viewer (`/library/[id]`) or Setlist Edit page (`/setlists/[id]/edit`).

## Fallback Behaviors
- **Empty Setlist in Page View:** When a setlist has 0 songs (`songs.length === 0`), the viewer renders an empty-state card indicating no songs are in the setlist yet, and keeps the "Edit Songs" FAB active for leaders to open the song selection modal.
- **Unreachable CAGED Shapes (> 7 Frets):** When a selected key results in a CAGED shape root requiring a capo position greater than 7 semitones, that CAGED button is visually styled as disabled and has `disabled={true}` with `aria-disabled="true"`.
- **Sync Network Disconnect:** If real-time broadcast channel `setlist_sync:${setlistId}` disconnects or encounters an error while in Page View mode, `liveSyncState` displays the sync error in the compact header while local manual navigation, transpose, and chord drawer features remain fully responsive.
